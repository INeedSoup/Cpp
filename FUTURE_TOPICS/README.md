# Future topics: advanced C++

These are intentionally outside the current beginner-to-intermediate path. Add them after the existing lessons feel comfortable.

## Language and design

- Value categories, move semantics, perfect forwarding, and copy elision
- Rule of zero / three / five; custom copy and move operations
- Concepts, constraints, and advanced generic programming
- CRTP, policy-based design, and type erasure
- Coroutines and ranges/views
- Modules and library design
- Advanced `constexpr`, consteval, and compile-time programming

## Resource management and correctness

- Allocators, memory resources (`std::pmr`), alignment, and placement `new`
- Undefined behaviour, strict aliasing, object lifetime, and the memory model
- Sanitizers, static analysis, profiling, benchmarking, and fuzz testing
- Strong exception guarantees and error-design strategies

## Concurrency and systems

- Threads, mutexes, condition variables, atomics, and lock-free basics
- Async tasks, futures/promises, and executors (as toolchain support evolves)
- Networking, operating-system APIs, and inter-process communication

## Larger projects

- Unit/integration testing with Catch2 or GoogleTest
- Package management with vcpkg or Conan
- CMake targets, install rules, testing, presets, and CI/CD
- Logging, serialization, databases, and REST clients
- Data structures, algorithms, and competitive-programming patterns
